# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of NanoVector and memory safety seriously.

If you find a security issue or vulnerability (e.g., buffer overflows, memory corruption, SIMD boundary violations, or deserialization flaws):

1. **Do not open a public issue.**
2. Please report security issues via GitHub Security Advisories or by emailing security contact.
3. Include details of the environment, reproduction code or inputs, and potential impact.
4. You will receive a response within 48 hours, followed by a patch and coordinated advisory release.
